# Character and Word Counter

A responsive Character and Word Counter created as **Task 18** of
my **Web Development Internship at Veda Technology**.

## 📌 Project Overview

This project is a text-analysis tool that counts characters, words,
and sentences as the user types inside a textarea.

The counters update instantly using JavaScript DOM events.

## 🎯 Objective

The objective of this task was to practice:

- Input events
- JavaScript string methods
- DOM manipulation
- Live UI updates
- Text trimming
- Whitespace handling
- Basic validation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Live character count
- Live word count
- Live sentence count
- Maximum 5000 characters
- Remaining character count
- Clear text button
- Multiple-space handling
- Responsive design
